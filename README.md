# Acadêmico: Lucas Paulo de Souza Navegante
As atividades foram separadas em 3 pastas, cada uma com suas implementações e testes.

1. Instalar depedências:
`npm install`

2. Para rodar os teste de uma pasta específica utiliza-se:
`npx vitest run ./src/[NOME DA ATIVIDADE]`

3. Para rodas todos os testes utiliza-se: 
`npx vitest`
